# Upstream Relationship

Upstream sync is permanently disabled. `bramburn/qi` is severed from the upstream `pi` project (ADR-0002, `specs/adr/0002-sever-upstream-endpoints.md`) and maintains its own version line.

## What that means in practice

- No merging, rebasing onto, or cherry-picking upstream branches.
- No `origin/main` sync branches and no re-application of upstream patches.
- No links to upstream documentation from this site.
- No outbound requests to upstream network endpoints: version checks read the npm registry, and the install/telemetry endpoints are self-hosted or unset.

## Remotes

Two remotes may be configured in a development checkout:

| Remote | Purpose |
|--------|---------|
| `origin` | Historical reference to the original repository. Read-only, never pushed to |
| `fork` | `https://github.com/bramburn/qi.git` — the only writable remote |

All branches, tags, and pull requests target `fork`.

## Release line

Versions are bumped in lockstep across all workspace packages. The `[bramburn]` suffix in `qi --version` identifies the build. See [Fork Features](./features) for the release pipeline.

## Migration from `pi`

`qi` performs no automatic migration from `pi` state:

- Move `~/.pi` to `~/.qi`
- Rename `.pi/` project directories to `.qi/`
- Replace `PI_*` environment variables with `QI_*`

See the migration section of the repository README for the full procedure.

# qi — Local AI Coding Agent

qi is a local-first, terminal-native AI coding agent. It reads your codebase, edits files, runs shell commands, and searches the web — using your own API credentials, running entirely on your machine.

## What qi does

qi is an interactive CLI tool. You run it from your terminal, describe what you want to build or fix, and qi plans and executes the changes:

- **Reads and edits source files** across your project
- **Runs shell commands** — builds, tests, git operations, anything in your `$PATH`
- **Uses your own LLM provider** — no data leaves your machine
- **Augments itself** with custom tools, extensions, and prompts
- **Supports multiple providers** — Anthropic Claude, OpenAI GPT, Google Gemini, Groq, and more

## Design priorities

qi is developed as an independent project. Its priorities:

1. **Bun-first runtime** — install, build, check, and test all run under Bun
2. **Windows-first iteration** — the build pipeline and CI cover Windows explicitly
3. **Self-contained releases** — npm publishes to `@bramburn/*` and binaries ship on GitHub releases

See [Fork Features](./fork/features) for the feature list.

## Quick start

```bash
# Install the latest release
npm install -g @bramburn/qi-coding-agent

# Or use the prebuilt binary
# Download from https://github.com/bramburn/qi/releases

# Set your API key
export ANTHROPIC_API_KEY=sk-...

# Launch the interactive TUI
qi

# Or run a one-shot prompt
qi -p "Explain this function"
```

For full installation steps, see [Installation](./getting-started/installation).

## Architecture overview

qi is a TypeScript monorepo with five core packages:

| Package | Role |
|---------|------|
| `packages/coding-agent` | The CLI entry point, TUI, and user-facing commands |
| `packages/agent` | The agent runtime: state machine, tool execution, message loop |
| `packages/ai` | Unified multi-provider LLM API (OpenAI, Anthropic, Google, …) |
| `packages/tui` | Terminal UI primitives: input, rendering, keybindings |
| `packages/telemetry` | Vendor-neutral telemetry contracts and schemas |

For a deep dive, see the [Architecture](./architecture) section.

## History

qi began as a fork of the `pi` coding agent and is now maintained independently: the command is `qi`, published packages use the `@bramburn/qi-*` scope, and configuration lives under `~/.qi` and `.qi/`. See [Why a Fork?](./fork/why-fork) for the origin and [Sync Process](./fork/sync) for how upstream changes are handled.

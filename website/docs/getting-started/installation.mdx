# Installation

## Requirements

- **Bun** 1.0+ (primary runtime — see [Runtime support](../fork/features#runtime-support))
- **Node.js** 20+ (legacy; still used by some scripts and the `npm publish` step in `.github/workflows/publish.yml`. Being phased out.)
- **Windows**, **macOS**, or **Linux**
- An API key for at least one LLM provider (Anthropic, OpenAI, Google, etc.)

## Prebuilt binaries (fastest)

Download a prebuilt binary from the [GitHub releases](https://github.com/bramburn/qi/releases) page. Pick the archive for your platform:

| Platform | Archive |
|----------|---------|
| Windows x64 | `qi-windows-x64.zip` |
| Windows ARM64 | `qi-windows-arm64.zip` |
| macOS x64 | `qi-darwin-x64.tar.gz` |
| macOS ARM64 | `qi-darwin-arm64.tar.gz` |
| Linux x64 | `qi-linux-x64.tar.gz` |
| Linux ARM64 | `qi-linux-arm64.tar.gz` |

Extract and put the binary somewhere on your `PATH`. On Windows, the binary is `qi.exe`; elsewhere it is `qi`.

## Bun (recommended)

```bash
bun add -g @bramburn/qi-coding-agent
qi --version
```

## npm (legacy)

```bash
npm install -g @bramburn/qi-coding-agent
qi --version
```

## From source

```bash
git clone https://github.com/bramburn/qi.git
cd qi

# Install dependencies (Bun — primary)
bun install --ignore-scripts
# or, equivalently (Node — legacy):
# npm install --ignore-scripts

# Build
bun run build
# or: npm run build

# Run from source (no install needed)
./qi-test.sh
```

## API key setup

qi needs at least one provider API key. Set it as an environment variable before launching:

```bash
# Anthropic (recommended for coding)
export ANTHROPIC_API_KEY=sk-ant-...

# OpenAI
export OPENAI_API_KEY=sk-...

# Google
export GOOGLE_API_KEY=...
```

For multiple providers, set all the keys you want to use. qi will let you switch between them interactively.

## Verifying the install

```bash
qi --version
qi --list-models
```

If models appear, the install is working. Launch the interactive TUI:

```bash
qi
```
